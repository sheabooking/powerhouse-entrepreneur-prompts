# Powerhouse Entrepreneur Prompts

Free guided coaching skills for Claude, created by **Shea Johnson** (AI Business Coach).

This is the home base for every volume in the series. Add it once, and you can install any volume — plus new ones as they're released.

## The volumes

**Vol. 1 — The Foundation** (`powerhouse-clarity-coach`)
A full coaching journey through five phases: Clarity, Vision, Structure, Build, and Mindset. You'll walk away with three personalized coaching documents and two working templates.
[View the skill →](https://github.com/sheabooking/powerhouse-clarity-coach)

**Vol. 2 — Spiritual Enlightenment** (`powerhouse-spiritual-coach`)
A guided spiritual journey through five phases: The Inward Turn, The Release, The Alignment, The Expansion, and The Integration. You'll finish with your Soul Alignment Package.
[View the skill →](https://github.com/sheabooking/powerhouse-spiritual-coach)

## Install in Claude Code

Add the marketplace (one time):

```
/plugin marketplace add sheabooking/powerhouse-prompts
```

Then install whichever volume you want:

```
/plugin install powerhouse-clarity-coach@powerhouse-prompts
/plugin install powerhouse-spiritual-coach@powerhouse-prompts
```

To pick up new volumes and updates later:

```
/plugin marketplace update powerhouse-prompts
```

## Using the Claude app instead?

Open the volume's own repo (linked above), download `SKILL.md`, and follow the install steps in that repo's README.
